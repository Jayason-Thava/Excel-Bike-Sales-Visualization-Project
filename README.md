# Bike Sales Visualizations 🚴📊

## 📌 Project Overview
This project is a practice exercise in **Excel data visualization**.  
I worked with a dataset of bike sales and used **Pivot Tables** to summarize the data.  
From the Pivot Table, I created different types of charts and customized them to improve readability and presentation.

The main goals of this project were to:
- Learn how to build **Pivot Tables** for summarizing data.
- Create **Line Graphs, Stacked Bar Charts, and Pie Charts** from Pivot Table outputs.
- Edit and format charts by adding **titles, axis labels, and legends**.
- Practice presenting data visually in a clear and professional way.
